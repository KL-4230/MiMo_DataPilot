# MiMo_DataPilot 行业大数据智能研判与商业决策辅助分析中台

基于小米 MiMo-V2.5 超强推理与超长上下文能力打造的企业级数据分析决策平台，为市场调研、商业投资与行业运营提供全流程智能赋能。

## ✨ 核心功能
- 多源数据自动化处理：支持多渠道行业数据自动抓取、清洗、分类与整合归档
- 深度数据研判引擎：依托MiMo大模型实现市场趋势预测、行业风口分析、风险预警
- 可视化分析看板：自动生成标准化数据报表、趋势走势图、竞品对比分析表
- 商业决策智能推演：根据数据分析结果输出可落地的行业运营与投资规划方案
- 全栈部署架构：FastAPI后端服务 + 可视化前端界面，支持本地/云端双模式部署

## 🚀 快速启动
1. 配置MiMo API Key到项目`config/`目录下的配置文件中
2. 运行`start.sh`（Linux/macOS）或`run.bat`（Windows）启动服务
3. 访问本地服务地址进入数据中台控制台，即可开始数据解析与研判分析
